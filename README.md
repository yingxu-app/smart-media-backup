# 影序 YINGXU

> 摄影师的本地优先素材备份与归档工具。插卡、确认、备份、校验、可追溯。

[官网](https://yingxu-app.github.io) · [下载 macOS 版](https://github.com/luguanlin20050927/smart-media-backup/releases/latest) · [更新日志](https://yingxu-app.github.io/changelog.html) · [问题反馈](https://github.com/luguanlin20050927/smart-media-backup/issues)

## 给摄影师的三个步骤

1. 从官网下载 DMG，打开后把“影序 YINGXU”拖到“应用程序”。
2. 插入相机存储卡或读卡器，影序会扫描来源、文件数量、照片和视频。
3. 选择备份位置，确认事件名称和目录预览，点击“开始备份”。完成后可在“归档记录”打开报告、查询素材位置。

默认只读取、复制和校验，**绝不自动删除原卡素材**。首次备份保留每一个文件；再次备份同一来源到同一目标时会逐个跳过已完成文件。

## 当前候选版：v1.0.33

| 能力 | 当前行为 |
| --- | --- |
| 来源扫描 | 识别已挂载的存储卡、外接盘；显示文件、照片、视频与容量统计。 |
| 多目标备份 | 可选本地目录、外接硬盘；一个目标异常不会删除原卡素材。 |
| 增量跳过 | 基于来源路径、哈希与完成历史判断；不会把同内容但不同文件误判为重复。 |
| SHA-256 校验 | 复制后比对源与目标；报告和历史记录显示校验结果。 |
| 中断恢复 | 取消或目标不可用时记录部分完成状态、失败原因与报告路径，重新执行可继续处理未完成文件。 |
| 历史与报告 | 保留成功、跳过、失败、校验数量、来源卡、每个目标结果，并导出 JSON、CSV、Markdown 报告。 |
| 本地优先 | 素材和历史默认留在本机；百度网盘为可选项，未配置时不会影响本地备份。 |
| 影序 Pocket | 同一 Wi-Fi 下用手机查看桌面备份进度、历史并填写拍摄信息；无需安装原生 App。 |

## 影序 Pocket 手机协作台

1. 在 Mac 版“偏好设置 → 影序 Pocket”生成 6 位配对码。
2. 保持手机与 Mac 在同一 Wi-Fi，用手机 Safari 打开界面显示的局域网地址。
3. 输入配对码后，可查看实时进度、历史记录，并把事件、地点、设备和备注发送到当前 Mac。
4. iPhone 可在 Safari 的“分享 → 添加到主屏幕”中把它保存为接近 App 的入口。

Pocket 默认只在本地局域网工作，配对码十分钟后失效且只能使用一次。它不会读取、上传、删除或修改手机照片，也不能替代桌面端在后台读取整张存储卡。详见 [Pocket 使用说明](docs/POCKET.md)。

## macOS 安装与首次打开

1. 下载 `YINGXU-macOS-v1.0.33.dmg`，双击打开。
2. 将“影序 YINGXU”拖入“应用程序”。
3. 第一次打开时，因当前版本尚未完成 Apple 公证，macOS 可能提示“无法验证开发者”或“已损坏”。这是系统保护提示，不代表素材被修改。
4. 在“系统设置 → 隐私与安全性”找到影序，点击“仍要打开”；随后再打开即可。

请只从官网或本仓库 Releases 下载。发布页会提供对应 DMG 的 SHA-256，下载后可核对完整性。

## 目录与安全原则

目录由工作台中的“文件夹命名顺序”预览决定，可按时间、事件、地点、设备、照片/视频组合。

- 原卡始终是源，只读扫描和复制；
- 校验失败、取消、磁盘不可用、空间不足时，不允许清理原卡；
- 只有所有已选目标完成且校验通过后，界面才允许用户主动进入清理流程；
- 若设备或地点无法可靠识别，会明确显示待确认，不会假装猜测正确。

## 本机验证证据（v1.0.33）

在 macOS 与真实 `TF卡64G` 上完成两轮验收：

- 首轮：132/132 个文件复制并 SHA-256 校验通过；
- 同目标、同事件再次执行：0 复制、132 跳过、132 已校验；
- 26 项自动回归测试覆盖空卡、取消、目标不可用、空间不足、权限不足、同内容不同文件、重复跳过、拔卡模拟、多目标部分失败、数据库迁移、校验发现损坏文件、AI 不可用时扫描仍即时返回、导航页不会在后台反复扫描原卡、并发扫描去重，以及 Pocket 配对、访问隔离、状态、历史和拍摄信息接口。

物理拔卡、断电与 Windows 安装包尚未在本次发布环境完成实机验证。Pocket 已完成 Mac 本机接口和手机尺寸页面验收，仍需用户在实际 iPhone Safari 上完成一次同 Wi-Fi 配对确认。
