桌面软件与影序账号

影序以本地备份为主：扫描、原始照片/视频、绝对文件路径、校验和及备份报告默认保存在你的电脑或选择的目标位置。可选云盘或 AI 服务由用户自行配置；启用后，发送到对应服务的数据遵循该服务的隐私规则。

如果你主动启用影序账号同步，邮箱、注册用户名和你输入的密码会通过 HTTPS 发送给 Firebase Authentication，用于创建或验证账号；影序不会把密码保存在本机配置或 Realtime Database。备份进度与归档元数据（包括文件名、事件/地点/设备备注、状态、时间、数量、大小和目标显示名）会写入影序 Firebase Realtime Database，并按账号 UID 隔离。数据库部署在新加坡区域。原始照片、视频和电脑绝对路径不会上传到数据库；本机刷新令牌由操作系统凭据库保存。

退出影序账号只会清除本机登录状态，不会删除云端历史。目前应用没有云端历史删除入口；如需清除，请联系项目维护者。Firebase 服务由 Google 提供，账户验证和数据托管还受 Google/Firebase 相关条款约束。

iPhone Safari PWA

iOS 当前仅提供 Safari PWA，不提供原生 iOS App 或 App Store 版本。通过 HTTPS 打开并完成首次加载后，PWA 可缓存应用页面，使电脑关闭或暂时断网时仍能启动并查看本机缓存的云端历史；实时进度和云端刷新仍需要网络及对应设备已同步。Firebase 刷新令牌和缓存的历史元数据保存在该浏览器的 IndexedDB 中，退出账号会清除此 PWA 的本机缓存。用户在同一 Wi‑Fi 下配对电脑后，可明确选择照片、视频、RAW 文件或 Files 文件夹，并将选中的原始媒体直接传到该电脑已配置的备份目标；媒体不会上传到影序云端。电脑端以 SHA‑256 校验并记录历史。iOS 浏览器只开放用户选中的项目，不提供静默扫描整张相册/外接盘、向任意手机目录写入或锁屏后台持续复制的能力。局域网 HTTP 页面需要电脑运行，且不支持 Service Worker 离线缓存。

网站

本网站包含产品介绍、下载页面和影序 Pocket 账号协作页面。Pocket 会把邮箱和密码通过 HTTPS 发送给 Firebase Authentication 进行登录；注册时的用户名通过账号资料接口保存。登录后 Pocket 读取当前账号自己的备份进度和归档元数据，不上传原始照片、视频、密码或电脑绝对路径。页面不主动加载广告、统计或追踪脚本。点击 GitHub 等外部链接后，相关服务按其自身隐私规则处理连接信息。
