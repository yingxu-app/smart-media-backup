# 第一次使用影序

1. 从官网下载实际存在的 macOS 稳定安装包，并核对 SHA-256。
2. 打开 DMG，把“影序 YINGXU”拖入 Applications。
3. 无开发者公证时，第一次启动若被拦截，在“系统设置 → 隐私与安全性”选择“仍要打开”。
4. 从相机取出存储卡，通过读卡器连接电脑，再打开影序。
5. 检查来源名称、照片/视频数量与参考照片；多个来源需要逐个选择确认。
6. 调整日期、事件、地点、设备、媒体类型的命名顺序，并在层级预览中修改不准确的目录名。
7. 选择本地、外置硬盘或多个目标；确认可用空间和 SHA-256 校验。
8. 开始备份。过程中可以暂停、继续或取消；取消后历史记录保留为“部分完成”。
9. 完成页检查成功、跳过、失败和校验数字，打开目标目录或导出 JSON/CSV/Markdown 报告。
10. 只有所有目标完成且校验通过后，才允许用户主动清理原卡；默认不清理。
