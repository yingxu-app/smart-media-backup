# 影序 v1.0.30：P0–P5 产品就绪状态

本文只记录已经有实现或有验证证据的能力。没有 Windows、手机或苹果开发者账号的项目，不写成“已经完成”。

## P0 可靠性交付

- 核心复制、SHA-256 校验、增量跳过、取消后部分完成、目标空间不足、权限不足、来源中断、损坏文件、多目标独立结果均有自动回归。
- 历史数据库支持旧结构迁移；复制、跳过、校验、失败、目标结果与报告字段统一。
- 报告支持 JSON、CSV、Markdown；报告下载限制在本机配置目录，历史清空必须二次确认。
- macOS Apple Silicon `.app` 已构建并通过临时签名验证；无付费开发者账号，因此不能完成 Apple 公证。
- v1.0.30 DMG 已生成并通过系统镜像校验，应用本体也通过 ad-hoc 深度签名验证；未购买 Apple Developer 账户，因此不能完成 Apple 公证。

## P1 核心能力

- 可按每日拍摄日期、事件、地点、设备、照片/视频生成可编辑的目录层级预览。
- 多个来源单独扫描；多个目标单独显示复制、跳过、失败和校验结果。
- 历史支持状态、备份位置、关键词、日期筛选；可改名、清空和导出报告。
- 待确认废片统一进入 `待确认废片/照片` 与 `待确认废片/视频`，不自动删除原卡素材。

## P2 普通摄影师体验

- 插卡状态、来源卡片、参考照片、目标选择、可用空间、开始备份、暂停/继续、取消、完成结果均在桌面工作台内完成。
- 默认不清理原卡；只有全部目标完成并校验通过时才允许清理。
- 校验、百度网盘、AI、Webhook、同步等专业选项均附边界说明；AI 失败不会阻断基础备份。

## P3 平台边界

- macOS：当前主平台。
- Windows：CI 只验证代码可导入和测试；未经过 Windows 实机安装、SD 卡与 Defender 验收，所以官网继续标记“准备中”。
- 影序 Pocket：PWA 可记录素材清单、生成交接文件并与同一局域网桌面端配对。手机浏览器不能代替桌面程序后台读取整张存储卡。
- Android/iOS 原生应用：未购买开发者账号，也未做实机包，不宣称已经上线。

## P4 AI 与高级能力

- AI 自动命名可关闭，默认基础归档不依赖 AI；本地 Ollama 不可用时回退为空建议。
- 废片识别只进入“待确认”，不会自动删除。
- Lightroom、Final Cut、DaVinci 的正式工程互操作仍是后续项；目前只提供通用报告与目录结构。

## P5 公开展示

- README、架构、隐私、安全、贡献、测试矩阵、比赛案例和发布清单已齐备。
- 12 页比赛产品说明 PPT、对应 PDF、三分钟演示脚本与提交检查清单已完成。
- 官网保留旧页面回滚版本；公开下载指向实际存在且校验通过的 v1.0.30 DMG，并明确无 Apple 公证时的首次打开步骤。
- 发布自动化包含多平台测试和 macOS 打包流程；Apple 公证需要外部账号，Windows 实机与手机实机需要对应设备。

## 发布判定

v1.0.30 已具备公开下载、简历展示与普通用户试用条件。由于没有 Apple Developer 账户，它不是 Apple 公证版本，官网必须持续保留 Gatekeeper 手动放行说明。Windows 实机、手机原生应用和大容量 NAS 压力测试仍属于后续阶段，不能写成已经完成。
