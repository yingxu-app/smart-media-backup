网站

本网站是静态产品介绍与下载页面，不提供账号注册、照片上传或在线备份功能。页面不主动加载广告、统计或追踪脚本。点击 GitHub 等外部链接后，相关服务按其自身隐私规则处理连接信息。

桌面软件

影序以本地备份为主：扫描和文件校验在你的电脑上运行，素材写入你选择的目标位置。可选云盘或 AI 服务需要用户自行配置；启用后，发送到对应服务的数据遵循该服务的隐私规则。

Pocket 移动客户端

Pocket 包括手机网页（PWA）、微信小程序和原生移动客户端。连接时，客户端会向你填写的桌面电脑局域网地址发起本地连接；微信小程序和原生客户端会把该地址保存在本机，方便下次填写。一次性配对码只用于建立连接，会话令牌保存在当前运行内存中，不会被影序服务器接收。

配对后，手机可接收桌面备份状态和最近归档摘要。你在客户端填写的事件、地点、设备和备注会通过同一局域网发送到已配对电脑，并保存在该电脑的本地配置目录。影序不会通过自有云端中转这些信息，也不会通过 Pocket 读取或传输手机照片、视频。请仅在你信任的私人网络中开启桌面端 Pocket 监听并配对。

当前微信小程序代码不调用微信账号、通讯录、定位或相册接口。若未来增加平台权限、云端中继或其他数据处理方式，会先更新本说明及小程序用户隐私保护指引。

隐私问题

如需报告隐私问题，请通过 GitHub Issues 联系项目维护者。请不要上传照片、密钥或个人凭据。
