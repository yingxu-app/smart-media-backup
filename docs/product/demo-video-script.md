# 影序 YINGXU 3 分钟演示视频脚本

## 0:00-0:20 用户问题

摄影师每次拍摄后都要面对同一件事：卡里混着多个日期、多个设备的照片和视频。复制成功不代表内容安全，后期也经常不知道素材在哪块硬盘。

## 0:20-0:45 产品定位

影序是一款本地优先的摄影素材备份与归档工具。它把插卡、扫描、命名、复制、校验和历史检索串成一条清晰路径，面向不懂编程的普通摄影师。

## 0:45-1:25 真实工作流

1. 插入 SD 卡，影序自动识别来源并统计照片、视频和容量。
2. 按拍摄日期与设备拆分内容，展示参考照片。
3. 用户可以调整时间、地点、事件、设备和媒体类型的命名顺序，并预览最终文件夹层级。
4. 选择本地盘、外置硬盘或多个目标，开始备份。

## 1:25-2:05 可靠性

复制过程中，每个目标独立显示成功、跳过、失败和校验数量。任务取消或源卡中断后可以继续；重复备份会跳过已经完整存在的文件；SHA-256 校验确认源文件与备份文件内容一致。

演示历史记录：打开一次任务，展示目标盘、目标目录、开始与结束时间、失败原因，以及 JSON、CSV、Markdown 报告。

## 2:05-2:35 安全与隐私

影序默认本地运行，不上传原始素材。AI 命名、百度网盘和 Webhook 都是可选项，关闭后不影响核心备份。废片识别只进入“待确认”，绝不自动删除原片。

## 2:35-3:00 总结

影序希望让摄影师不再依赖记忆管理硬盘，而是用一套可验证、可继续、可追溯的流程守住每一次拍摄。

当前候选版为 v1.0.29，已完成 17 项自动化可靠性测试。尚未完成的 Windows 实机、手机后台文件访问和 Apple 公证均在材料中明确标注。
