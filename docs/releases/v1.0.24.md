## 已明确的边界

- 本版未进行 Apple Developer 签名和公证；首次打开可能需要用户在“系统设置 → 隐私与安全性”选择“仍要打开”。
- Windows、Android、iPhone 原生版没有在对应实机上构建和验收，因此官网不提供虚假的正式下载。
- 本次没有物理执行拔卡、断电、电脑睡眠恢复和满盘测试；这些场景在后续有对应硬件环境时需补充实测记录。
- 原卡素材默认不删除；任何失败、取消或未校验状态都不应进入清理流程。
