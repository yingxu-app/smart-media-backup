# 影序 YINGXU v1.0.30 发布验收

发布日期：2026-07-29

## 本次修复

- 存储卡扫描不再同步调用可选 AI 服务；
- 首页与来源列表加入请求防重入，避免定时轮询叠加；
- 归档记录与偏好设置页只检查原卡挂载状态，不再每五秒重复读取 EXIF；
- 即使 Ollama 未启动，设备识别、日期分组和文件夹预览仍可离线工作。

## 验收要求

- 19 项自动化测试全部通过；
- macOS App 版本、DMG 文件名、官网和 GitHub Release 均为 `1.0.30`；
- DMG 通过 `hdiutil verify`，App 通过 ad-hoc 深度签名检查；
- 从公开下载地址重新安装后，本地工作台可打开，健康检查返回 `1.0.30`；
- 用户历史数据库和设置保留，原始存储卡不做删除或写入。

## 已知边界

本版本没有 Apple Developer 账户，因此未进行 Apple 公证。首次打开仍需按官网说明在“系统设置 → 隐私与安全性”允许运行。Windows 实机、手机原生应用和用户物理拔卡复核不属于本次补丁范围。
