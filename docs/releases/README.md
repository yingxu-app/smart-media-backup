## 写新记录时

- 文件名用 `vX.Y.Z.md`，一次候选一个文件，不要覆盖旧文件。
- 开头三行固定写：日期、状态（已发布 / 本机候选 / CI 候选 / 未验收）、构建产物与 SHA-256。
- 明确区分“CI 跑通”“本机装过”“真机验收过”，三者不能互相替代。
- 没有真机验收的版本，不要在 README 或官网写成正式发布。
