# 影序 YINGXU v1.0.31 发布验收

发布日期：2026-07-29

## 本次修复

- 同一张外置存储卡在任意时刻只执行一次真实目录遍历；
- 并发请求复用同卡已完成缓存，尚无缓存时返回“正在读取”并由工作台自动重试；
- 避免多个 `os.scandir` 同时读取 FAT/exFAT 卡造成首页长时间停在等待状态；
- 保留工作台缓存、来源选择、历史记录和用户设置，升级不清空数据。

## 验收要求

- 20 项自动化测试全部通过；
- macOS App、DMG、官网和 GitHub Release 版本统一为 `1.0.31`；
- DMG 通过 `hdiutil verify`，App 通过 ad-hoc 深度签名检查；
- 从公开下载地址删除旧安装后重新安装，工作台能识别真实 `TF卡64G` 的 66 个文件；
- 原始存储卡不做删除或写入，历史数据库和设置继续保留。

最终 DMG SHA-256：`6ba459330c5537498bd77300ad983d3cf2de6d844b2add752a90a0e357a18707`

## 已知边界

本版本没有 Apple Developer 账户，因此未进行 Apple 公证。首次打开仍需按官网说明在“系统设置 → 隐私与安全性”允许运行。Windows、手机、比赛材料与用户物理拔卡复核不属于本次补丁范围。
