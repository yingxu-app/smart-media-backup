# 发布测试矩阵 v1.0.31

| 场景 | 自动化 | macOS 本机 | 结果要求 |
| --- | --- | --- | --- |
| 空卡 | 是 | 是 | 拒绝开始，不产生伪成功 |
| 重复备份 | 是 | 是 | 显示跳过数量，不重复复制 |
| 同内容不同文件 | 是 | 是 | 首次全部保留 |
| 用户取消 | 是 | 是 | 已取消或部分完成，报告可开，原卡安全 |
| 来源中断/拔卡 | 模拟 | 待再次物理复核 | 部分完成，可重试，禁止清理 |
| 目标不可用 | 是 | 是 | 明确失败原因，原卡安全 |
| 目标空间不足 | 模拟 | 可用小容量卷复核 | 开始前拦截，显示所需/可用空间 |
| 目标无权限 | 模拟 | 是 | 明确权限错误，不修改原卡 |
| 目标内容损坏 | 是 | 是 | SHA-256 失败并记录 |
| 多目标一处失败 | 是 | 是 | 其他目标继续，每个目标独立结果 |
| 旧数据库升级 | 是 | 是 | 历史记录保留，新字段可用 |
| 报告 | 是 | 是 | JSON、CSV、Markdown 均可打开 |
| AI 服务不可用 | 是 | 是 | 扫描即时完成，AI 超时不阻塞存储卡识别 |
| 同卡并发扫描 | 是 | 是 | 只启动一次真实遍历，其他请求复用缓存或立即等待 |
| Windows | CI 构建预览 | 未实机 | 官网标注准备中，不发布正式承诺 |
| iPhone/Android | PWA 能力说明 | 未实机 | 不承诺后台读取或自动传输 |
