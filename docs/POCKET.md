# 影序 Pocket 使用说明

影序 Pocket 是 macOS 桌面端附带的局域网手机协作台，不需要 App Store、Apple 开发者账号或额外服务器。

## 使用步骤

1. 打开 Mac 上的“影序 YINGXU”。
2. 进入“03 偏好设置”，找到“影序 Pocket”。
3. 点击生成配对码。页面会显示一个局域网地址和 6 位配对码。
4. 确保 iPhone 与 Mac 连接同一个 Wi-Fi，在 Safari 打开该地址。
5. 输入配对码完成连接。配对码 10 分钟后失效，并且只能使用一次。
6. 配对后可查看桌面备份进度、历史记录，也可填写拍摄信息和备注。
7. 在“手机文件备份到电脑”填写归档名，点“从照片或文件中选择”选择媒体；也可在 iOS Safari 18.4+ 点目录选择器，选 Files 中的 SD 卡/文件夹。扫描预览会读取所选文件并计算 SHA‑256；同一批重复内容会标记并跳过。
8. 点“开始备份到电脑”后，文件经当前 Wi‑Fi 分块发送到桌面上次选定的备份目标。桌面端再次计算 SHA‑256；校验成功才会保留文件并写入历史。可在分块之间暂停或取消；桌面偏好设置同步显示手机导入进度。
9. 如需桌面图标，在 Safari 中选择“分享 → 添加到主屏幕”。

Pocket 当前用 `http://<Mac 局域网 IP>:8080` 提供局域网页面。局域网 HTTP 不属于普通 HTTPS 安全上下文，Service Worker 页面缓存不可用；在线状态、历史、备注和原件传输都需要 Mac 在线并保持同一局域网。独立 HTTPS PWA 仍可在电脑离线时打开缓存页面和历史。

## 安全边界

- Pocket 只监听当前 Mac 的局域网地址，桌面工作台、归档记录和偏好设置不会对局域网访客开放。
- 手机必须使用一次性配对码才能访问状态、历史和拍摄信息接口。
- 手机会话默认 12 小时后失效，也可主动断开或在桌面端撤销。
- 只有用户主动选中的媒体才会传输；媒体在同一局域网内发送到电脑已配置的目标盘，不上传到影序云端。
- 手机原件保持只读，不会删除或修改。桌面端写入前核对文件大小和路径；传输完成后重新计算 SHA‑256，校验失败会清理临时文件。
- iOS 浏览器不能保证锁屏或切换应用后持续工作。页面离开前可能会暂停或断开；已完成的文件已校验并记入历史，未完成的临时文件会在取消/断开后清理，重新选择文件后可重试。
- 浏览器不能直接写入任意手机目录，也无法在电脑离线时把选中的大文件可靠排入后台队列；要保存到手机或外接盘，请用浏览器分享/文件导出方式，或使用原生客户端。

## 常见问题

### 手机打不开地址

确认手机和 Mac 在同一个 Wi-Fi，Mac 版影序仍在运行，并暂时关闭会隔离局域网的 VPN 或访客 Wi-Fi。局域网地址只在当前网络中有效。

### 手机能否直接备份整张相册或存储卡

浏览器只允许用户从照片或 Files 选择器明确授权的项目；iOS Safari 18.4+ 可通过目录选择器选择可访问的文件夹。它不能静默扫描整张相册或外接盘，也不能保证锁屏后台复制。请分批选择，保持页面在前台；电脑须在线并与手机在同一 Wi‑Fi。

### 是否需要联网服务器

不需要。Pocket 页面和接口均由当前 Mac 上的影序提供，默认不会把素材发送到影序服务器。
