macOS 安装

  1. 下载 .dmg → 拖到 Applications
  2. 打开启动台 → 点 App
首次弹出「未验证开发者」
系统设置 → 隐私 → 「仍然打开」
右键 → 点「打开」即可

Windows 安装

  1. 下载 .exe → 双击运行
  2. 从桌面快捷方式启动
弹出「已保护你的电脑」
点「更多信息」→「仍要运行」
